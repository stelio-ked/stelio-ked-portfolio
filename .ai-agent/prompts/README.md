# Prompts-modelo do Padrão Ked

Um prompt por etapa do fluxo. Copie, troque o que está entre `< >` e cole no chat do Claude Code.
Cada etapa tem uma skill; o prompt é o jeito de chamá-la com o contexto certo.

| Etapa | Arquivo |
| --- | --- |
| 0. Projeto já em desenvolvimento | `00-projeto-existente.md` |
| 1. Bootstrap (projeto novo) | `01-bootstrap.md` |
| 2. Product features | `02-product-features.md` |
| 3. Revisão com o público-alvo | `03-revisao-negocio.md` |
| 4. Análise técnica | `04-tech-assessment.md` |
| 5. Ambiente local | `05-env-setup.md` |
| 6. Design system | `06-design-system.md` |
| 7. Codar | `07-codar.md` |
| 8. Revisão e PR | `08-revisao-pr.md` |
